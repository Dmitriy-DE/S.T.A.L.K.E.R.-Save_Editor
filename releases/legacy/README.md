# Historical packages

These are the original, unmodified v0.1.0 and v0.3.0 EXPERIMENTAL source bundles supplied by the project owner. SHA256SUMS identifies them. They contain a Linux x86_64 decoder and require Python/Tkinter; they are not standalone desktop executables or Windows builds.

The unpacked v0.3.0 source is the repository baseline. No v0.2.0 archive was supplied. Personal saves, screenshots, the full conversation handoff, the pyooz wheel and the SteamCloudFileManager archive remain in the ignored local `.local/original-import-2026-09-13/` directory. The original root files are retained there with a manifest; no originals were deleted.

Future platform binaries belong in GitHub Releases with SHA-256 checksums, source tag, dependency provenance and platform test results. Do not put generated build directories or personal game data in Git.
