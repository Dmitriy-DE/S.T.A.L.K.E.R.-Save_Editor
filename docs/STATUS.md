# Состояние и пробелы — 2026-09-26

## SC-2 — внешний Steam Cloud helper удалён

PR [#194](https://github.com/Dmitriy-DE/S.T.A.L.K.E.R.-Save_Editor/pull/194)
удаляет helper discovery/AppImage extraction, subprocess transport,
helper UI/diagnostics/packaging paths и их IPC-тесты. Cloud использует native
RemoteStorage worker, Steam web через CDP для чтения/скачивания и существующие
write guards. Локальные gates: full pytest (941 passed), Ruff, mypy и web bundle check;
[GitHub Actions](https://github.com/Dmitriy-DE/S.T.A.L.K.E.R.-Save_Editor/actions/runs/36259731656)
PASS на Ubuntu/Windows с Python 3.11/3.12. Live Steam Cloud read/write и game
load не проверялись.

## v0.7.2 — официальные названия, звуки из игры, слоты по играм — 2026-09-25

- **Официальные названия на 13 языках** (#137). `tools/build_official_names.py`
  собирает из строковых таблиц Enhanced Edition имена предметов, апгрейдов и
  группировок ТЧ/ЧН/ЗП в `web/catalog_names.json` (только имена). Реальные
  кодировки: cp1251 (ru/uk), cp1252 (en/de/fr/it/es), cp1250 (pl/cs), UTF-8 у
  ja/ko/zh, хотя в заголовках везде windows-1251. pt_BR и tr — английские
  имена, игр на этих языках не было. Самодельные таблицы `locales/items`
  удалены. Исправлено наследование `inv_name_short`: технические материалы ЗП
  назывались «КПК».
- **Звуки и музыка меню из установленной игры** (#137). Если стоит оригинал или
  EE, берутся её звуки меню (`ui_mm_main_c.xml`) и инвентаря, декодируются Qt
  Multimedia и кэшируются (~26 МБ на три игры); переключатель «Музыка из
  главного меню игры» тихо играет `menu_music`. Ничего не распространяется;
  без игры остаются синтезированные звуки. HD-иконок в EE нет: атлас тот же
  1024×2048 с клеткой 50 px.
- **Перезапуск после смены языка** (#136): сразу предлагается, на выбранном
  языке.
- **Слоты по играм** (#138). Размещение в X-Ray предлагает и принимает только
  рюкзак, пояс для артефактов и собственный слот предмета (записан игрой);
  раньше можно было положить хлеб в слот шлема. Названия слотов по игре: ЗП
  считает с 1 (нож 1 … шлем 12, проверено на сейвах), ТЧ/ЧН — с 0.
- **S2: детектор, ПНВ, бинокль, чертежи.** Объекты актёра вне рюкзака с
  kind 6/8/10/11 раньше выпадали (детектор «Велес» и 4 чертежа на последнем
  сейве); теперь видны только для чтения. Где S2 хранит надетые ПНВ/бинокль,
  на имеющихся сейвах проверить нельзя: у персонажа их нет.

## v0.7.1 — правильные имена S2, названия и апгрейды для всех игр — 2026-09-25

Правки по живой проверке v0.7.0 на Linux.

- **S2: имена предметов были чужими.** В сейве идут подряд пять таблиц строк;
  первый байт `type_key` выбирает таблицу (4 — таблица с `GunAK74_ST`, 5 —
  следующая, …), а парсер всегда брал первую. Отсюда «Rook_Svoboda_Armor ×10
  по 0,25 кг» (на деле энергетики), «второй экзоскелет» (на деле Сайга Д-12) и
  пустые/лживые вкладки оружия и брони. Теперь 1143 предмета из 34 читаемых
  реальных сейвов разрешаются без единого пропуска, категории берутся из
  kind-кода (0 оружие, 1 броня, 2 артефакт, 4 расходник, 5/7 патроны и гранаты,
  8 квестовое/хабар).
- **S2: апгрейды и состояние.** Оружие без апгрейдов (Kharod, Сайга) теперь
  читается вместе с модулями; у брони читается вектор установленных апгрейдов
  (18 у экзы «Монолита»). Названия SID собираются из переводимых фрагментов
  (`editor/s2_names.py`): «9×39 мм · бронебойные», «Пси-защита · ур. 2»,
  «Глушитель · ур. 3», «Экзоскелет · Монолит». Парсер помечает одиночные
  расходники, патроны и гранаты S2 как стаки, но запись количества в S2
  закрыта (`edit_stacks = research`), пока правка не подтверждена загрузкой в
  игре (docs/roadmap ED-3). Запись апгрейдов S2 по-прежнему выключена: для неё
  нужен пересчёт размеров записи.
- **Трилогия: названия, апгрейды и часть иконок не работали в сборке.**
  `web/catalogs.json` не попадал в PyInstaller — установленная программа
  показывала `bandage` вместо «Бинт», «Улучшение 1…4» и не давала ставить
  апгрейды. Исправлено; добавлены английские и украинские таблицы имён
  (`locales/items/*.json`, 768 названий), остальные языки берут английские.
  Для сейвов модов (OGSM и т.п.) имена и иконки читаются из `gamedata` мода —
  только для показа, правки по-прежнему идут по официальным данным.
- **Одинаковые предметы объединяются** в одну строку (каждая пачка патронов и
  буханка в X-Ray — отдельный объект); переключатель «Объединять одинаковые».
- **Быстрая сводка** в библиотеке заполняется фоновым чтением выбранного
  сейва, не дожидаясь открытия.
- **Настройки:** кнопки слева переключают страницы (раньше прокручивали к
  уже видимому разделу); выбор языка больше не меняется колесом мыши при
  прокрутке.
- **Звуки** под меню каждой игры: металлический щелчок ТЧ, треск помех ЧН,
  мягкие клики ЗП, воздушные блипы S2; тема меняется при выборе игры в
  библиотеке, лёгкий звук при наведении на вкладки.
- **Логи и отчёты об ошибках:** журнал ≤256 КБ + 1 копия, перехват
  необработанных ошибок и падений (`faulthandler`), при следующем запуске
  предлагается отправить обезличенный отчёт; кнопка «Отправить отчёт» в
  настройках.
- **Иконки:** для предметов без картинки — нарисованные силуэты по типу
  (пистолет, дробовик, экза, аптечка, патроны, ключ-карта…).

## v0.7.0 — языки, живые карточки сейвов, звук и анимации — 2026-09-25

- **Тексты.** Убран жаргон из пользовательских сообщений (Cloud operation,
  WriteFile, reconciliation, backup, snapshot…), единое обращение на «ты»,
  «Можно изменять / Только чтение» вместо одиноких прилагательных, размеры в
  «МБ», подсказки к «Экспериментально», горячие клавиши на Ctrl (одиночные
  S/F/R срабатывали из таблицы).
- **15 языков** (`editor/i18n.py`, `locales/*.json`, общие для desktop и web):
  все языки, на которых выходили трилогия и S.T.A.L.K.E.R. 2. Язык берётся из
  настроек → системы → английский; смена — «Настройки → Интерфейс», с кнопкой
  перезапуска. Классификаторы ошибок работают через `source_text()`, поэтому
  не зависят от языка. Названия предметов X-Ray берутся из `text/<язык>` игры;
  встроенный каталог пока только русский — для других языков, если игра не
  найдена, имена остаются русскими. Регионы S2 вне uk/ru — английские
  официальные названия.
- **Карточки сейвов.** X-Ray: `.dds`-скриншот рядом с `.sav`. S2: JPEG из
  `SaveGames/Thumbnails/<GUID>.sav`, регион и время игры из
  `CampaignsSave.sav` (`editor/s2_campaigns.py`, только чтение; разобраны 50 из
  52 реальных слотов, остальные — старый формат).
- **Звук и анимации.** Тихие синтезированные звуки ПДА (свой тон для каждой
  игры, S2 — мягче), плавная смена экранов; переключатели в шапке и громкость
  в настройках, в вебе учитывается `prefers-reduced-motion`. Игровые звуки не
  распространяются.
- **Новое:** перетаскивание файла в окно, сравнение двух сейвов, имя/здоровье/
  рейтинг/репутация/дата в игре для X-Ray (только просмотр).
- **Не сделано:** HD-иконки — иконки X-Ray остаются оригинальными 50×50,
  источника высокого разрешения с понятной лицензией нет; апскейл даёт только
  мыло. Типы сейвов S2 (авто/быстрое/ручное) в индексе есть, но значения не
  подтверждены — не показываются.
