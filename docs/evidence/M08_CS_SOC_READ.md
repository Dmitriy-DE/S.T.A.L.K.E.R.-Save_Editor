# M08 — Clear Sky и Shadow of Chernobyl read blocker

Проверка выполнена 2026-09-15 на ветке M08. Карточка требует принятого M07
чтения CoP и принятого M06 контейнера, после чего — отдельные evidence для CS
и SoC. Для каждого поля нужны три независимые пары, а сейв каждой игры должен
отвергаться при попытке открыть его как другую игру.

## Наблюдение

M07 остаётся `blocked` в [PR #54](https://github.com/Dmitriy-DE/S.T.A.L.K.E.R.-2-HoC---Save_Editor/pull/54),
потому что M06 не принята и в рабочем дереве нет реального X-Ray corpus.
Публичные материалы подтверждают наличие инструментов для SoC/CS/CoP, но не
подменяют controlled corpus, version matrix или game-load checks. В частности,
Enhanced Editions нельзя считать совместимыми с оригиналом по одному сходству
контейнера или расширению `.sav`.

## Решение

M08 **заблокирована зависимостью от M07 и отсутствием CS/SoC corpus**. В реестр
не добавляются `stalker-cs` и `stalker-soc`; общая реализация X-Ray и таблица
версий не проектируются по догадке. Не выполняются и не объявляются пройденными
negative tests «CS как SoC» / «SoC как CS».

## Разблокировка

Нужны принятые M06/M07, реальные сейвы обеих игр для каждой заявляемой версии,
три независимые пары на каждое поле, заголовок/версия и точные SHA. Отдельно
нужны synthetic negative fixtures, подтверждённые как чужая игра, и
controlled проверки Enhanced Editions; затем — полный Linux gate и сверка с
игрой.

## Gate

Функциональный код M08 не менялся. После появления corpus обязательны:

```text
PYTHON=.venv/bin/python make check
PYTHON=.venv/bin/python make test
```
