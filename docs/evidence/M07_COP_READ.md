# M07 — Call of Pripyat read blocker

Проверка выполнена 2026-09-15 на ветке M07. Карточка требует сначала принять
M06: распаковка X-Ray и byte-for-byte round-trip для CoP должны быть доказаны на
реальном корпусе. После этого каждое поле (деньги, предмет, количество,
положение и метаданные) должно пройти минимум три независимые пары и сверку с
игрой.

## Наблюдение

M06 остаётся `blocked` в [PR #53](https://github.com/Dmitriy-DE/S.T.A.L.K.E.R.-2-HoC---Save_Editor/pull/53):
в рабочем дереве нет реальных `.sav`, `.bak` или `.scop`, а публичная схема
raw LZO1X пока не даёт принятого round-trip для конкретной версии CoP.
Подробное исследование и команда проверки корпуса находятся в
[XRAY_CONTAINER](XRAY_CONTAINER.md).

Без принятого контейнера невозможно отличить корректно прочитанное поле от
смещения внутри неверно разобранного payload. В частности, ни деньги, ни
инвентарь, ни уровень/время игры не имеют локального evidence.

## Решение

M07 **заблокирована зависимостью от M06 и отсутствием CoP corpus**. В реестр не
добавляется `stalker-cop`, не реализуются `detect`/`inspect`, и `prepare` не
меняется. Никакие значения не объявляются прочитанными.

## Разблокировка

Нужны принятый M06 round-trip для целевой версии CoP, минимум три независимые
пары сейвов с известным изменением каждого поля, исходные SHA и результаты
сверки с отображением игры. После этого M07 можно продолжить отдельным code
проходом и сохранить исходный файл неизменным.

## Gate

Функциональный код M07 не менялся. Полный существующий Linux gate остаётся
обязательной проверкой после появления corpus:

```text
PYTHON=.venv/bin/python make check
PYTHON=.venv/bin/python make test
```
