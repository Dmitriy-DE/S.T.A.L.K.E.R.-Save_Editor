# M09 — trilogy edit blocker

Проверка выполнена 2026-09-15 на ветке M09. Условие входа карточки — принятое
чтение каждой игры и byte-for-byte round-trip для её контейнера. Приёмка также
требует загрузить отредактированную копию в самой игре, проверить значение,
сохраниться заново и записать результат.

## Наблюдение

M08 остаётся `blocked` в [PR #55](https://github.com/Dmitriy-DE/S.T.A.L.K.E.R.-2-HoC---Save_Editor/pull/55):
нет принятого M07/M06 и реального корпуса SoC, CS или CoP. Значит, для
трилогии не доказаны ни контейнер, ни расположение денег/стаков, ни границы
EditPlan. Игровой Windows runtime и controlled load/re-save на этой машине
также отсутствуют.

## Решение

M09 **заблокирована зависимостью от M08 и отсутствием игрового corpus/runtime**.
`prepare` для X-Ray форматов не добавляется, существующий `EditPlan` не
расширяется, а деньги, стаки, backup и atomic write не получают новых
неподтверждённых путей. Нельзя выдавать локальный Linux gate за доказательство
того, что игра поймёт изменённый файл.

## Разблокировка

Сначала нужны принятые M06–M08 с SHA round-trip и полями, доказанными на
контролируемых парах. Затем для каждой игры нужны копия, ожидаемая правка,
собственная проверка результата, загрузка в соответствующей игре, новое
сохранение и evidence результата. Только после этого можно реализовывать
минимальные подтверждённые money/stack edits.

## Gate

Функциональный код M09 не менялся. Текущая документационная ветка должна
проходить существующий Linux gate:

```text
PYTHON=.venv/bin/python make check
PYTHON=.venv/bin/python make test
```
