## Что перенесено в runtime

Из Stitch reference перенесены только визуальные решения:

- charcoal/olive/rust palette и высококонтрастные состояния focus/hover/error;
- верхняя строка с названием, версией, источником, filename, размером/SHA,
  CRC и осторожным статусом формата;
- левая навигация по существующим Qt-вкладкам;
- metric cards для parser-backed money/inventory и честные `—` для ещё не
  доказанных location/time;
- responsive Qt Widgets layout без изображений, web bundle или нового
  runtime package.

Static demo values из `code.html` (имя сейва, деньги, дата, координаты и
технические записи) не используются. При открытии файла badges и cards
заполняются только из `LocalSnapshot`/`SaveInfo`. Полная UE5 GVAS schema
текущим parser не подтверждается, поэтому shell показывает `UE5 GVAS: НЕ
ПОДТВЕРЖДЁН`, даже когда контейнер и CRC валидны.

## Проверенное состояние

Красная фаза: до реализации `tests/test_ui_theme.py` завершался двумя
`AttributeError`, поскольку старый `MainWindow` не имел shell metadata и
навигации. После минимальной реализации:

```text
QT_QPA_PLATFORM=offscreen /tmp/save-editor-ui-venv/bin/python -m pytest tests/test_ui_theme.py -q -> 2 passed
QT_QPA_PLATFORM=offscreen /tmp/save-editor-ui-venv/bin/python -m pytest tests -q -> 105 passed
```

Offscreen screenshot smoke выполнен на synthetic/empty state и сохранён во
временный `/tmp/save-editor-ui-shell.png`; это не native Windows, DPI или
keyboard acceptance. Packaged artifacts не пересобирались после U07 и поэтому
остаются привязанными к предыдущему B01 source commit.

## Ограничения и следующие gates

`Music Creation Tool` не является зависимостью и не копируется в проект.

остаются отдельными P03/B02 gates.
