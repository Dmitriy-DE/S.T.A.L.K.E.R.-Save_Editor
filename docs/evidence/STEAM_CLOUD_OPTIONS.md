# Steam Cloud: какие пути записи существуют — 2026-09-14

Вопрос владельца: раз есть
<https://store.steampowered.com/account/remotestorage>, нельзя ли обойтись без
локального helper?

Короткий ответ: **скачать оттуда можно, залить — нет.** Ниже разобранные
варианты и почему остаётся текущая схема.

## Разобранные варианты

| Путь | Чтение | Запись | Вывод |
|---|---|---|---|
| Страница `account/remotestorage` | да, файлы видны и скачиваются по кнопке | **нет**, формы загрузки не существует | Годится как источник файла для веб-редактора |
| Steam CEF Cloud page через локальный CDP | **да** | **нет** | Desktop может использовать авторизованную Steam web-сессию для списка и download URL |
| Steam Web API `ISteamRemoteStorage` | — | **нет** | Это про Workshop/UGC (`GetPublishedFileDetails`, `GetCollectionDetails`), не про облачные сейвы пользователя |
| Steamworks client API `ISteamRemoteStorage::FileWrite` | да | **да** | Работает только внутри процесса с запущенным Steam и контекстом app_id. Ровно это и делает `SteamCloudFileManager` — helper, который уже используется |
| Синхронизация клиентом Steam | да | да | Steam сам заливает файл из локальной папки сейвов при выходе из игры. Требует установленного Steam и самой игры на машине |

## Почему из браузера записать нельзя

Загрузка в Cloud выполняется процессом, который аутентифицирован как
запущенное приложение: Steam-клиент знает app_id, сессию и владельца. Вкладка
браузера ни того, ни другого предоставить не может, а веб-интерфейс Valve
сознательно даёт только чтение. Это не ограничение нашей реализации и не
обходится ключом или токеном.

## Что из этого следует для проекта

1. **Десктопная версия сохраняет полный цикл**: native/helper подключается для
   записи; если список RemoteStorage пуст, приложение читает Steam
   `remotecache.vdf` и, после явного включения CEF debugging, получает список и
   download URL из авторизованной Steam web-сессии. Загружает отредактированную
   копию native Steam API и различает `verified` и `uncertain`.
2. **Веб-версия — только локальные файлы**, и это написано в интерфейсе прямо,
   без спрятанной неработающей вкладки.
3. **Рабочий сценарий для GeForce NOW без установленного Steam** выглядит так:
   скачать слот со страницы remote storage → открыть в веб-редакторе →
   скачать изменённую копию → залить обратно **десктопной версией** или
   положить в локальную папку сейвов, чтобы Steam синхронизировал сам.
   Промежуточного звена «залить из браузера» не существует.

Если Valve когда-нибудь добавит запись в веб-интерфейс, менять придётся один
модуль транспорта: `editor/transactions.py` уже не знает, чем именно
выполняется запись.
