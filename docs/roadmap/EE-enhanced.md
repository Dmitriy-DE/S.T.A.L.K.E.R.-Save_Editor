# EE — Enhanced Editions (ТЧ, ЧН, ЗП)

**Факт.** Официально сейвы оригиналов и EE несовместимы (FAQ GSC). Сейчас «no EE adapter registered» (`docs/evidence/EE_FORMATS_2026-09-15.md`). Все три EE установлены, сейвов нет.

## EE-1 — Сейвы EE (делает владелец)

По каждой из трёх EE, в Steam через Proton, сделать сейвы:

1. сразу после начала новой игры;
2. после подбора нескольких предметов (записать каких);
3. после продажи или покупки — чтобы изменились деньги (записать сумму);
4. с артефактом на поясе, с надетой бронёй, с оружием с апгрейдом (где есть);
5. поздний сейв, если есть.

**Итого:** 5–10 сейвов на игру. Имена — латиницей, без ника.

**Где лежат:** `compatdata/<2427410|2427420|2427430>/pfx/drive_c/users/steamuser/Saved Games/<EE-папка>/STEAM/savedgames`. Редактор их находит сам.

По желанию те же действия в оригинале. Это даёт пары «оригинал vs EE» для сравнения.
