# KB — S.T.A.L.K.E.R. 2: названия, иконки, знания (срочно)

**Источники по степени доверия:**

1. **Официальная русская локализация игры** — ru-вики `Модуль:S2Localization/data/ru/part1..5`.
   - Ключи: `sid_items_<SID>_name`, `sid_questItemprototypes_<SID>_name`, `sid_upgrades_<SID>_name`, а также `sid_locations_*`.
   - Это строки из файлов игры один в один.
2. **Инфобоксы en-вики** (stalker.fandom.com, CC BY-SA).
   - Поля: `hoc_code`/`code` (SID; у уникального оружия суффикс `_Player`), `hoc_name`/`name`, `hoc_icon`/`icon`.
   - В тексте статьи: «is a unique [[AR416]]».
3. **`data/s2_sources.json`:**
   - вручную сопоставленные имена и картинки fextralife;
   - 252 пары SID→English из списка item-ID gamepressure, сверенные с официальными русскими именами (Glutton = «Обжора», Lullaby = «Колыбельная» и т.д.).
4. **Межъязыковые ссылки вики** — для остальных языков.

**Правило показа.**

- Официальное имя на языке интерфейса.
- Если его нет — английское.
- Если нет и английского — составное имя из переведённых фрагментов (как сейчас).
- Русское официальное имя показывается только в русском интерфейсе.
- Сырой SID не показывается никогда, кроме «технических деталей».

## KB-2 — Названия и иконки S2 в desktop и web

**Кто:** Claude · **Размер:** M · **Зависит:** KB-1 · **Уровень:** L3

**Шаги.**

1. Новый модуль `editor/s2_items.py`:
   - `load` (кэш), `install(payload)` для web;
   - `canonical_sid(sid)`: точное совпадение → без учёта регистра → `GuardGun*` → `Gun*` → без суффикса `_Player`;
   - `s2_official_name(sid, language=None)`, `s2_icon_name(sid)`, `s2_variant_of(sid)`.
2. `editor/s2_names.py`: официальное имя первым по правилу показа, затем текущая логика.
   - Для чертежей: «Чертёж: <официальное имя оружия>».
   - `_EXACT` оставить только для того, чего нет в базе.
3. `editor/item_names.module_label`: апгрейды S2 через `s2_official_name`.
4. Иконки на desktop:
   - `ui/xray_assets.py` — каталог иконок по корню `assets/icons`;
   - для S2 искать `assets/icons/s2/<canonical>.png` по `display_name` (SID) до глифа категории;
   - детальная карточка и слоты экипировки берут то же.
5. Web:
   - `web_bridge` отдаёт `icon: "s2/<SID>"` в строке предмета;
   - `app.js`: кандидаты `[item.icon, item.type_key, item.name]`;
   - `bootstrap.js` грузит `s2_items.json` и вызывает `bridge.install_s2_items` (без него страница работает);
   - `tools/build_web_bundle.py`: добавить `editor/s2_items.py` в MODULES.
6. Упаковка: `packaging/editor.spec` — `assets/icons/s2` и `web/s2_items.json`.

**Тесты.**

- Позитивные:
  - `GunAK74_ST` → en «AKM-74S», ru «АКМ-74С»;
  - `GuardGunAK74_ST` → то же;
  - `EArtifactBattery` → en Battery, ru «Батарейка»;
  - апгрейд `GunAK74_Upgrade_Barrel_1` → ru «Прорезиненное покрытие».
- Негативные:
  - неизвестный SID → составное имя;
  - файла базы нет → никакого исключения;
  - пустой SID → None;
  - в не-русском языке никогда не появляется кириллица из ru-базы.
- Web bridge возвращает `icon`. Тест свежести bundle.

**Приёмка.**

- Из `.deb` и с живого web открыть реальный сейв S2: у оружия, патронов, артефактов и расходников официальные имена и иконки.
- Скриншоты в 3 языках (ru, en, uk) в PR.
