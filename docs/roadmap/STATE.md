## Идеи и новые задачи из этой сессии

- ~~SC-1~~ сделано (#169). Было: запись в облако для игр с Auto-Cloud = локальная папка + сеанс «запуск игры» 60 с + сверка с сервером через веб. `FileWrite` для таких игр отключить. Кнопка в UI «Синхронизировать через запуск игры» (её запускает сам владелец). Подсказки при «Cloud Conflict».
- **SC-2:** текущий PR удаляет внешний Steam Cloud helper; локальные gates зелёные, GitHub jobs не стартуют из-за account billing restriction.
- **SC-3:** достижения Steam, как Steam Achievement Manager (просмотр, разблокировка, сброс), тем же нативным воркером.
- **S2-FACTIONS (новое):** в S2 есть отношения с группировками (подсказка при загрузке). Ресерч по паре сейвов «до и после изменения отношений».
- **S2-STASH:** разобрать `PlayerStash` по скриншотам трофеев.
- Остальное — по трекеру: волна 2 (RL-1/2/3/5, ED-1, ED-2 стадия 1 «дубль», CP-2 звуки в приложении, KB-6), волна 3 (EE после сейвов EE, TP, MOD-2), волна 4 (C#).

## Правила работы (важно для следующей сессии)

- Без субагентов и Workflow (`memory/no-agents.md`). Codex и Gemini — через брифы, которые владелец передаёт сам.

- Проверки кода: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q -p no:cacheprovider`, `ruff`, `mypy`, `node --experimental-default-type=module --test tests/js/*.test.mjs`, `tools/build_web_bundle.py --check`, `tools/build_provenance.py` после изменения ассетов.
