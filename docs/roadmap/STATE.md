## Открытые проблемы (баги)

1. **OTA на Linux (ST-2) всё ещё не работает.** При обновлении открывается окно пароля pkexec и через ~2 секунды закрывается само (отчёт владельца 2026-09-26, после #142 с `sh`-обёрткой). Гипотезы: `sh` и pkexec получают SIGHUP/SIGTERM, когда редактор выходит (нужен `start_new_session=True`/`setsid` у `Popen`), либо polkit-агент теряет родителя. Проверить: запустить handoff вручную из терминала, затем из приложения с `setsid`. L4 не пройден.
2. **Облако S2: запись через `FileWrite` создаёт файлы-двойники в корне по умолчанию** (без папки `WinAppDataLocal`). Игра их не видит. На сервере остались два таких файла (`Data/610B5C….sav`, `Data/99457897….sav`, 26.09): удалить может владелец через «View Steam Cloud» или команда с подтверждением.
3. **Правильный путь записи в облако S2 найден (2026-09-26):** положить файл в локальную папку Auto-Cloud (`compatdata/1643320/.../Local Settings/Application Data/Stalker2/Saved/STEAM/SaveGames/Data/`), затем держать сеанс Steam API от имени игры ~60 с (`SteamAppId=1643320`, `SteamAPI_Init` → `RunCallbacks` раз в секунду → `SteamAPI_Shutdown`). Steam засчитывает запуск («Last played: Today») и синхронизирует облако. Короткие дочерние операции воркера (~1 с) этого **не** вызывают. В первом прогоне появился «Cloud Conflict», потому что на сервере был более новый сейв из GFN. Владелец разрешает его в Steam. Итог проверки в игре ещё не получен.
4. **Статус «persisted» врёт** (SC-1): он означает только локальную запись. Нужна сверка с сервером через веб-режим (CEF 8080) и честный статус.
5. `tools/ui_review/capture_all.py` сейчас в `main` (из #156). Кандидаты на обрезку после исправлений: китайская декоративная цитата в настройках (6 px, высота закреплена тестом под окно 620 px).

## Идеи и новые задачи из этой сессии

- **SC-1 (переписать):** запись в облако для игр с Auto-Cloud = локальная папка + сеанс «запуск игры» 60 с + сверка с сервером через веб. `FileWrite` для таких игр отключить. Кнопка в UI «Синхронизировать через запуск игры» (её запускает сам владелец). Подсказки при «Cloud Conflict».
- **SC-2:** убрать запасной SteamCloudFileManager helper.
- **SC-3:** достижения Steam, как Steam Achievement Manager (просмотр, разблокировка, сброс), тем же нативным воркером.
- **S2-FACTIONS (новое):** в S2 есть отношения с группировками (подсказка при загрузке). Ресерч по паре сейвов «до и после изменения отношений».
- **S2-STASH:** разобрать `PlayerStash` по скриншотам трофеев.
- Остальное — по трекеру: волна 2 (RL-1/2/3/5, ED-1, ED-2 стадия 1 «дубль», CP-2 звуки в приложении, KB-6), волна 3 (EE после сейвов EE, TP, MOD-2), волна 4 (C#).
