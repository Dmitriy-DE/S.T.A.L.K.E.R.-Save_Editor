**Кто:** Claude (ultracode-ресерч) · **Размер:** L · **Зависит:** D2 (S2 установлена), RL-5 · **Уровень:** L5 · **Статус:** blocked

**Стадии.** Каждая — отдельный PR и отдельный L5.

1. **Дублировать предмет, который уже есть.**
   - Взять запись того же SID из этого же сейва как шаблон.
   - Выделить новый handle.
   - Разместить в сетке: свободная клетка по размеру предмета.
   - Обновить массивы инвентаря (`_rebuild_inventory_arrays`), вес и счётчики.
   - Сделать round-trip.
2. **Любой SID, который есть в таблицах имён сейва** (`S2NameTables`). Шаблон записи берётся из корпуса RL-5: запись того же kind из другого сейва, где такой SID был.
3. **Произвольный SID.** Нужно добавить строку в таблицу имён. Отдельное исследование индексов `type_key` и всех ссылок на таблицу.

**Исследование** (записать в `docs/evidence/S2_ADD_<дата>.md`):

- диффы сейвов «до и после подбора предмета в игре»: владелец делает пары сейвов;
- аллокатор handle'ов, ссылки на предмет из других структур;
- поведение при несовпадении веса.

**Приёмка по стадии.**

- Сейв → добавить → игра загрузила → предмет виден и работает → пересохранение → редактор разобрал.
- Негативные тесты: нет места в сетке, неизвестный SID, повреждённый шаблон.
- Capability `add_items` для S2 включается по kind: сначала расходники и патроны, потом остальное.
