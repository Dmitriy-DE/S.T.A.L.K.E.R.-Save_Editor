# MOD — Мод-компаньон внутри игры и Workshop

**Факты (2026-09-25).**

- Workshop: S2 (Zone Kit) и три EE. У оригиналов Workshop нет.
- EE-моды: конфиги, скрипты, шейдеры и ресурсы упаковываются XrCompress for LotZ и загружаются через SteamCMD. `.dll`/`.exe` запрещены и игрой не загружаются. Источник — официальный гайд GSC в Steam (id 3497576322).
- В EE есть `gamedata/` и `lua51.dll`.
- S2 Save/Load guide: `ModWorldSubsystem` (`ShouldSaveData`, `OnSaveDataLoaded`, `OnSaveDataRequested`, `SetDataForSave`) хранит **данные мода** в сейве, до 10 МБ. Это не API правки инвентаря. `ModWorldSubsystem` создаётся на всех уровнях, включая главное меню.

**Решения:** D10 (что вообще можно распространять через Workshop) и D11 (править живую игру, а не файл).

## MOD-1 — Ресерч

**Кто:** Gemini (черновик) → Claude (проверка) · **Размер:** M

Вопросы, по каждому ответ с URL источника.

**Оригиналы ТЧ, ЧН, ЗП:**

- Lua-функции для денег: `db.actor:give_money`, `transfer_money`.
- Предметы: `alife():create(section, pos, lvid, gvid, parent_id)`, `alife():release`.
- Ремонт: `item:set_condition`.
- Отношения и ранг: `relation_registry`, `set_character_rank`, `set_community_goodwill`.
- Телепорт: `db.actor:set_actor_position` в пределах уровня; для перехода между уровнями — `alife():teleport_object`, создание `level_changer` или готовые решения из известных модов.
- Своё окно: `CUIScriptWnd`, XML-формы, горячая клавиша (`on_key_press` через callback'и `bind_stalker`), пункт в главном меню (`ui_main_menu.script`).
- Отличия API между ТЧ, ЧН и ЗП.

**EE:**

- Что разрешено в модах: скрипты `gamedata/scripts`, UI XML.
- Как включаются моды: меню модов.
- Влияние модов на достижения и сейвы.
- Отличия Lua API от оригиналов.
- Полный текст официального гайда: конспект.

**S2:**

- Можно ли из Blueprint-мода дать игроку предмет или деньги (функции уровня `XSpawnItemNearPlayerBySID`), сделать виджет в меню.
- Требования Zone Kit: EGS, Windows, объём, частичная загрузка.

**Результат:** `docs/research/INGAME_COMPANION.md`.

## MOD-2 — POC компаньона для оригинальной ЗП

**Кто:** Claude (дизайн, ревью) + Codex (Lua) · **Размер:** L · **Зависит:** MOD-1, D11 · **Уровень:** L5

**Объём POC.**

1. `gamedata/scripts/save_editor_companion.script` и XML-окно.
2. Открытие по горячей клавише в загруженной игре.
3. Вкладки:
   - деньги (+ и −);
   - выдать предмет: список секций из каталога, поиск, количество;
   - починить экипировку;
   - перенос в якорные точки (данные из TP-2).
4. Все действия только через штатный API. После действия — подсказка «сохранитесь».
5. Каталог предметов и точек генерируется из данных редактора (`web/catalogs.json`, TP-2) скриптом `tools/build_companion.py` в `.script`/`.ltx`. Одни данные — два фронтенда.
6. Установка: копирование в `gamedata/` игры. Бэкап изменённых файлов, если они были.

**L5.** Владелец в игре: деньги, предмет, ремонт, перенос → сохранение → редактор видит изменения в сейве.
