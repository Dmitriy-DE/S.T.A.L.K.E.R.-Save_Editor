# RS — Ресерч без привязки к фиче

## RS-1 — Что ещё можно вытащить из сейвов, по каждой игре

**Кто:** Claude (+ черновик Gemini по публичным описаниям формата) · **Размер:** M

**Уже известно** (из сессии 2026-09-24/25):

- **X-Ray:**
  - квестовые флаги (InfoPortions) читаются: ЗП у актора 889, ТЧ 370;
  - время игры (чанк 5);
  - позиция актора;
  - реестры чанка 9;
  - патроны в магазине и флаги аддонов оружия — не разобраны, размер записи не меняют.
- **S2:**
  - контейнер `PlayerStash` (тайник);
  - репутация, голод и т.п. — строками.
- Вкладка «Оружие» уже включает оружие из рюкзака S2 (102 надето, 43 в рюкзаке по сейвам владельца).

**Шаги.**

1. По каждой игре таблица: поле → где лежит → проверено на значениях → только чтение или кандидат в запись.
2. Кандидаты в UI «Сведения» (только чтение): время, уровень и позиция, прогресс сюжета (число и названия выполненных InfoPortions, официальные строки), статистика, тайник S2.

**Результат:** `docs/research/SAVE_CONTENTS.md` + предложения карточек.
