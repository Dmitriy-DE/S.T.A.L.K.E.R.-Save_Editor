# CP — Медиа и content packs

**Факты.**

- С приложением уже едут:
  - иконки трилогии: 563 PNG, 4,3 МБ, из официальных атласов;
  - иконки S2: из вики и fextralife;
  - официальные названия.
- Аудио извлекается из установленной игры один раз и кэшируется в `user_data_dir/sounds/game-v{N}`.

**Решение:** D4 — музыку и звуки GSC в приложение не класть.

## CP-1 — Манифест происхождения ассетов

**Кто:** Codex · **Размер:** S · **Уровень:** L2

**Шаги.**

1. `tools/build_provenance.py` генерирует `assets/PROVENANCE.json`.
   - Формат записи: путь или маска → `{source, origin_url, basis, generator}`.
   - `basis`: `own` (наша графика), `ofl` (шрифты), `game-derived` (иконки трилогии из атласов EE), `wiki-cc-by-sa` (вики), `fextralife`.
   - Генератор знает о каждом наборе: `assets/icons/xray` ← `tools/build_icon_pack.py`, `assets/icons/s2` ← `tools/build_s2_catalog.py`, `assets/chrome`, `assets/ui/*`, `assets/fonts`.
2. Тест: каждый файл в `assets/` и `web/icons/` покрыт записью, и нет записей без файлов.
3. `THIRD_PARTY_NOTICES.md`: ссылка на манифест и атрибуция CC BY-SA для вики.

## CP-3 — Локальные content packs с отпечатком сборки

**Кто:** Claude (дизайн) → Codex · **Размер:** M · **Зависит:** D4, RL-6 · **Уровень:** L3

**Дизайн.**

```text
user_data_dir/content/<release>/<fingerprint>/
    manifest.json   # версия схемы, fingerprint, дата, источник, что извлечено
    audio/…         # звуки и музыка меню
    names.json      # при наличии — имена из файлов установленной игры
    icons/…         # при наличии — иконки из установленной игры
```

- `fingerprint`: Steam `buildid` + sha256 ключевых архивов (размер и mtime как быстрый фильтр).
- Извлечение делает дочерний процесс (`ui/worker_process.py`), как сейчас для аудио.
- При смене отпечатка — пересборка в фоне; до её конца используется старая версия.
- Doctor (RL-3) показывает статус каждого pack'а.
- Миграция текущего кэша `sounds/game-v*` в новую схему.

**Кто:** Claude · **Размер:** M · **Зависит:** D2
