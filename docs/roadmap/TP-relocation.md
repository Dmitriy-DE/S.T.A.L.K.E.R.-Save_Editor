# TP — Перенос персонажа («телепорт», experimental)

**Принцип (D12).**

- Только известные безопасные точки.
- Предпросмотр: уровень и название точки. Бэкап. Метка experimental.
- Произвольных XYZ нет.
- В ТЧ нет проводников — это не мешает: точки берутся из переходов между уровнями, они есть во всех трёх играх.

## TP-1 — Ресерч: позиция и уровень актора в сейве X-Ray

**Кто:** Claude (ultracode) · **Размер:** M

**Вопросы.**

1. Поля актора в ALife: `o_Position`, `o_Angle`, `m_tGraphID` (game vertex), `m_tNodeID` (level vertex). Где лежат в сериализации для ТЧ, ЧН и ЗП (`editor/xray_save.py`).
2. Как игра выбирает уровень при загрузке: по game vertex актора через `game.graph`? Что ещё в сейве завязано на текущий уровень — имя уровня в заголовке (уже читается как `level_name`), онлайн и офлайн объекты.
3. Что меняется в сейве при штатном переходе через level changer.

**Метод.**

- Пары сейвов от владельца: «стою здесь» → «прошёл 50 м» → «перешёл на соседний уровень».
- Дифф полей.

**Результат:** `docs/evidence/XRAY_ACTOR_POSITION_<дата>.md`.

## TP-2 — Точки назначения

**Кто:** Codex · **Размер:** M · **Зависит:** TP-1 · **Уровень:** L2

**Шаги.**

1. `tools/build_relocation_anchors.py`: читает `all.spawn` установленной игры (через `editor/xray_catalog.read_xray_asset`) и достаёт объекты `level_changer`: `dest_game_vertex_id`, `dest_level_vertex_id`, `dest_position`, `dest_direction`, `dest_level_name`.
2. Для ЧН и ЗП дополнительно — точки проводников из скриптов и конфигов (путь найти в TP-1).
3. Имена точек: официальное имя уровня (`web/catalog_names.json` или строковые таблицы EE) + «вход со стороны X».
4. Выход: `web/relocation_anchors.json` — только координаты и id, без ресурсов игры.

**Тесты:** синтетический `all.spawn` с одним level changer.

## TP-3 — Перенос в пределах уровня

**Кто:** Claude · **Размер:** M · **Зависит:** TP-2 · **Уровень:** L5

**Шаги.**

1. Writer: позиция, game vertex и level vertex актора в точку на **том же** уровне. Размер записи не меняется.
2. Capability `relocate` (experimental) только для проверенных игр.
3. UI: вкладка «Персонаж» → «Перенести» → список точек текущего уровня.

**L5.** Загрузка в игре: персонаж в точке, не застрял, сохранение и загрузка работают.

## TP-4 — Перенос между уровнями

**Кто:** Claude · **Размер:** L · **Зависит:** TP-3 · **Уровень:** L5

**Шаги.**

1. Точка на другом уровне: game vertex другого уровня и всё, что TP-1 назовёт обязательным (имя уровня в заголовке и т.д.).
2. Сначала ЗП, потом ЧН, потом ТЧ.
3. Негатив: квестовые блокировки (уровни, закрытые сюжетом) → точка недоступна до нужного этапа, если этап читается из сейва (InfoPortions, RS-1).
