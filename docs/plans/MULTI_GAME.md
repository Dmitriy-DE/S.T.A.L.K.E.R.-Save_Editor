# План: несколько игр серии и работа с реальными папками сохранений

> Этот файл — вход для исполнителя. Читать целиком до первой строки кода.
> Задание разбито на карточки `M01…M07`; порядок в таблице — рабочий.

## Что просит владелец

1. В программе выбрать игру серии, закинуть сейв, отредактировать.
2. В десктопной версии указать путь к игре / папке сейвов / Steam — **или**
   чтобы программа сама нашла и позволила выбрать слот прямо оттуда.

## Что нужно понять до планирования

**Это не «добавить выпадающий список».** S.T.A.L.K.E.R. 2 сделан на Unreal
Engine 5: контейнер сжат Kraken, внутри — UE-структуры, и текущий парсер знает
ровно два поля (деньги, стаки инвентаря) по найденной сигнатуре.

Старая трилогия — Shadow of Chernobyl, Clear Sky, Call of Pripyat — это движок
X-Ray. Другой контейнер, другое сжатие, другая раскладка. **Общего с парсером
S2 там нет ничего, кроме расширения файла.** Каждая игра — отдельный парсер,
который надо реверсить с нуля по реальным сейвам.

Отсюда порядок работы: сначала архитектура, которая умеет держать несколько
форматов и честно говорить «этот файл я не знаю», потом выбор игры и поиск
папок, и только потом — форматы, каждый под свой evidence-гейт.

**Нельзя** выкатывать выпадающий список с названиями игр, за которыми нет
парсера. Пользователь выберет «Call of Pripyat», получит ошибку и решит, что
программа сломана.

## Границы, которые нельзя перейти

- Не угадывать offsets. Поле считается найденным, когда оно воспроизводится на
  нескольких контролируемых сейвах и подтверждается изменением в игре.
- Не расширять `MONEY_ANCHOR` на другие игры. Это сигнатура S2, найденная на
  сейвах одного прохождения.
- Не трогать исходный файл. Любая правка — в новую копию, как сейчас.
- Не добавлять в UI игру, у которой нет парсера, даже «заглушкой».
- Не ломать текущий контракт: `EditorService`, `EditPlan`, backup/CRC/round-trip
  остаются.

## Справочная информация

### Steam

Корень Steam:

| ОС | Где искать |
|---|---|
| Windows | реестр `HKCU\Software\Valve\Steam` → `SteamPath`; запасной `%ProgramFiles(x86)%\Steam` |
| Linux | `~/.steam/steam`, `~/.local/share/Steam`, `~/.var/app/com.valvesoftware.Steam/data/Steam` (Flatpak) |

Библиотеки игр перечислены в `<steam>/steamapps/libraryfolders.vdf` — текстовый
VDF, разбирается без внешних зависимостей. Установленная игра лежит в
`<library>/steamapps/common/<имя>`, её манифест — `appmanifest_<appid>.acf`.

App ID: S.T.A.L.K.E.R. 2 — **1643320** (уже используется в `steam_cloud.py`).
Для старой трилогии ID нужно **проверить**, а не взять из этого файла на веру.

### Папки сохранений

| Игра | Windows | Примечание |
|---|---|---|
| S.T.A.L.K.E.R. 2 | `%LOCALAPPDATA%\Stalker2\Saved\SaveGames\` | в Steam Cloud путь `Stalker2/Saved/STEAM/SaveGames/Data/` — уже в коде |
| Трилогия X-Ray | `Documents\STALKER-<игра>\savedgames\` | конкретные имена папок проверить на живой установке |

Linux: игры серии идут через Proton, поэтому пути лежат внутри префикса —
`<library>/steamapps/compatdata/<appid>/pfx/drive_c/users/steamuser/...`.
Это **обязательная** часть M03: без учёта Proton поиск на Linux найдёт пусто.

### Что уже есть в проекте

- `editor/platforms.py` — пути пользовательских данных и поиск helper по ОС.
  Расширять здесь, а не заводить второй модуль путей.
- `editor/codec.py` — загрузка декодера, в том числе регистрация чужого
  (используется веб-сборкой). Тот же приём годится для формата.
- `editor/service.py` — единственная точка, через которую ходят все интерфейсы.
  Реестр форматов подключается сюда, а не в UI.
- `web/` — браузерная сборка на том же ядре. Всё, что добавляется в ядро,
  автоматически доступно и там; всё, что добавляется в `ui/`, — нет.

## Как проверять

Каждая карточка: сначала падающий тест, потом минимальная реализация, потом
`make check` и `make test`. CI гоняет Linux и Windows × Python 3.11/3.12 —
проверка путей обязана работать на обеих ОС, поэтому файловую систему в тестах
подменять, а не полагаться на машину исполнителя.
