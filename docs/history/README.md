# Архив документации

Здесь лежат завершённые handoff-файлы, импортные отчёты и старые инструкции,
которые полезны для происхождения проекта, но не являются текущим рабочим
контрактом.

Текущие требования находятся в корневом `AGENTS.md`, а актуальная документация
собрана в [docs/README.md](../README.md). Исторические записи не используются
для определения текущих возможностей, release gates или доказанности формата.
