## Контракт

Qt shell получает тёмную Zone-палитру, верхнюю строку метаданных и
CRC/формат badges, боковую навигацию по существующим вкладкам и карточки
сводки. Все значения после открытия берутся из текущего `LocalSnapshot`;
неизвестные location/time остаются `—`. `EditorService`, parser, storage,
cloud transaction и публичные widget attributes не меняются по смыслу.

## Ограничения

Окно показывает подтверждённые parser fields и честные placeholders. Реальные
названия предметов, location/time, durability, attachments, add/clone/delete
не появляются из одного макета. Native Windows/DPI/keyboard и packaged
startup остаются gates B02/P03; offscreen Qt не заменяет их.
