# M05 — Ручные пути и их запоминание

**Зависимости:** M04. **Gate:** code. **Priority:** P2.

## Scope

Если автопоиск не нашёл или нашёл не то — пользователь указывает вручную:
корень Steam, папку игры или папку сохранений. Указанное имеет приоритет над
найденным.

Хранить в существующем каталоге пользовательских данных
(`editor/platforms.user_data_dir()`), рядом с настройками. Формат — JSON с
версией схемы. Битый или чужой файл настроек не должен ронять запуск: читать
best-effort и продолжать с пустыми настройками.

## Чего не делать

Не хранить абсолютные пути в репозитории и не коммитить настройки. Не считать
сохранённый путь вечным: если он исчез, сообщить и предложить выбрать заново.

## Проверка

- Ручной путь перекрывает автопоиск.
- Сохранённый путь исчез → понятное сообщение, автопоиск снова доступен.
- Битый JSON настроек → запуск проходит, настройки пустые.
- `make check`, `make test`.
