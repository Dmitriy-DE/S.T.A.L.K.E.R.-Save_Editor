# M19 — Иконки инвентаря и визуальный слой

**Зависимости:** M11, M18. **Gate:** code. **Priority:** P2.

## Scope

Подключить к инвентарю уже найденные release-scoped метаданные X-Ray:
`inv_grid_x`, `inv_grid_y` и `icons_texture`. Desktop получает crop из
официального `ui_icon_equipment.dds` выбранной установки или проверенного
официального asset archive. Web не получает доступ к папке игры и поэтому
показывает маленький доступный категорийный glyph в той же Zone-палитре.

## Границы

Игровые `.dds`, шрифты, UI XML и модовые ресурсы не копируются в Git и не
отправляются в браузер. Если официальный atlas недоступен, Qt использует
репозиторный категорийный glyph; это явно не выдаётся за настоящую картинку
предмета. Неизвестный `type_key` не получает выдуманную иконку из каталога.

## Результат — 2026-09-16

Qt `InventoryTableModel` выдаёт `DecorationRole` в колонке имени. `InventoryView`
использует `XRayIconResolver`: он кэширует декодированный atlas, читает только
официальный unpacked tree или verified packed volume и добавляет те же icons в
список добавления предметов. Web bridge передаёт atlas metadata, а таблица
показывает компактный category glyph с `aria-label` и координатами official
atlas в tooltip, когда они известны.
