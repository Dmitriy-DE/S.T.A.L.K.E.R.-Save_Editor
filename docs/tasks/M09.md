# M09 — Редактирование трилогии

**Зависимости:** M08. **Gate:** code. **Priority:** P3.

## Условие входа

Начинается только после того, как для игры принято чтение **и** round-trip
собирает файл байт в байт. Без этого правка означает «переписать файл, который
мы не умеем собрать обратно».

## Scope

`prepare` для форматов трилогии: деньги и количество подтверждённых стаков —
ровно то же, что уже умеет S.T.A.L.K.E.R. 2. Через существующий `EditPlan`, с
существующими гарантиями: привязка к SHA источника, backup, атомарная запись,
проверка результата после сборки.

## Обязательная проверка в игре

Отредактированный сейв загружается в самой игре, значение совпадает с
ожидаемым, игра продолжает работать после сохранения заново. Без этого
карточка не принята: побайтовый round-trip доказывает, что файл собран, а не
что игра его поймёт.

## Чего не делать

Создание предметов, клонирование, удаление, прочность, модификации — не в этой
карточке и не по догадке.

## Проверка

- Правка денег и подтверждённого ammo stack на синтетическом fixture и
  in-memory на локальном корпусе каждой игры.
- Исходный файл не изменяется; копия проходит повторный parser round-trip,
  SHA и общий backup/atomic export path.
- Запись в самой игре пока не выполнена; поэтому game-load/re-save gate не
  объявляется пройденным.
- `make check`, `make test`.

## Результат прохода 2026-09-15

`prepare_xray` редактирует actor money и оба подтверждённых ammo count поля
(STATE и UPDATE), сверяет исходный SHA и перечитывает результат. Добавлен
строгий object-window индекс (`SPAWN`/`STATE`/`UPDATE`) и length-changing
registry framing. Synthetic/catalog-backed regression доказывает clone/remove
одного ammo record с новым `object_id`; это не включено как production add
control, потому что реальный catalog на текущем хосте не содержит доказанных
prototype bytes. Move, equipment, durability, upgrades, attachments и прочие
item classes остаются read-only. Enhanced Editions и game-load/re-save gate
остаются внешними ограничениями.

Актуальные локальные commits: `4448b71` (X-Ray inventory writer), `1c9cd80`
(capability-driven Qt/web). Полный локальный suite после UI/web слоя: 257
passed; Linux package и Cloudflare deployment проверены отдельным проходом.
Windows, загрузка сейва самой игрой и Enhanced Editions остаются открытыми
gates. Подробные хэши и deployment read-back: `docs/evidence/RELEASE_2026-09-15.md`.
