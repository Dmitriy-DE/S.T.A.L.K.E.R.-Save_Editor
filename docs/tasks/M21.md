# M21 — Read-only каталог прототипов S.T.A.L.K.E.R. 2

**Зависимости:** M11, M19. **Gate:** research → code. **Priority:** P2.

## Scope

Добавить общий read-only reader для официальных loose-файлов S2
`Content/GameLite/GameData/ItemPrototypes/*.cfg`. Каталог содержит точные
prototype SID, категорию, вес, max stack, слот и найденные upgrade SID. Qt и
явно сгенерированный browser bundle несут эти release-scoped metadata fields.

Изменение не открывает S2 writer. Prototype SID не объявляется compact
`type_key` из `.sav`: связь между ними не доказана. PAK extraction, save
mutation, локализация и Enhanced Editions не входят в карточку. Workshop и
Zone Kit loose trees допускаются только отдельным catalog-only overlay path.

## Границы canonical и overlay

Canonical reader ищет только `Content/GameLite/GameData` под явно выбранным
официальным корнем, пропускает symlink и очевидные `~mods`, `Mods`,
`SavedMods`, `pak__mods` и известные mod roots. Отдельный opt-in
`load_overlay` принимает loose Zone Kit/Steam Workshop tree для catalog-only
исследования; он не смешивает overlay с canonical root и не меняет save
capabilities. PAK-файлы не разбираются. Пустой или повреждённый resource tree
даёт `None`, а не частично выдуманный каталог.

`serialization_family` у S2 definitions остаётся `None`, `prototype` остаётся
`None`, а `FormatCapabilities.add_items/edit_upgrades` остаются выключенными.
Пустой faction catalog в desktop bundle означает отсутствие доказанной S2
faction schema, а не отсутствие группировок в игре.

## Реализация

- `editor/s2_catalog.py` разбирает вложенные `struct.begin/struct.end`, точные
  SID, наследование через `refkey` и item/upgrade metadata;
- `_Stalker2Format` подхватывает каталог при обходе родителей выбранного
  локального сейва, официальных install roots, явных Zone Kit roots и Steam
  Workshop `content/1643320`;
- `tools/build_web_catalogs.py` умеет экспортировать S2 metadata bundle, а
  `catalog_bundle` принимает S2 release без обязательного faction section;
- `web/pysrc.json` включает тот же reader, без второго браузерного parser;
- личные сейвы и игровые архивы в репозиторий не добавлялись.

## Результат — 2026-09-16

Синтетический official-style tree проверяет Bandage/GunAKU, вложенные upgrade
SID и отказ mod overlay. Реальный S2 каталог на машине не собран: S2 не
установлен, поэтому текущий сайт не получил статический список S2 items. Для
появления такого списка нужен локальный official resource root и отдельная
генерация metadata bundle.

## Продолжение — 2026-09-20

Добавлены display names для standalone upgrades, source discovery для
official install/Zone Kit/Steam Workshop и отдельный opt-in Workshop overlay
для loose CFG. Synthetic coverage теперь также проверяет эти источники и
вложенный Workshop layout. Текущая source boundary зафиксирована в
[S2 Zone Kit / Steam Workshop evidence](../evidence/S2_ZONEKIT_WORKSHOP_2026-09-20.md).

S2 save mapping, add/remove/clone, durability, attachments/upgrades в самом
`.sav` и game load/re-save остаются следующими evidence gates.
