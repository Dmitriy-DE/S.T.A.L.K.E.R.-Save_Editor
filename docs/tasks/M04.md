# M04 — Выбор слота из найденной папки

**Зависимости:** M03, M02. **Gate:** code. **Priority:** P2.

## Scope

В Qt-интерфейсе: список найденных сохранений — имя слота, размер, время
изменения, определённая игра. Выбор открывает слот тем же путём, что и «Открыть
.sav…» сейчас.

Пустой список — не ошибка: показать, где искали, и оставить ручной выбор файла.

Сортировка по времени изменения, свежие сверху: последний сейв нужен чаще
всего.

## Чего не делать

- Не открывать слот автоматически при старте. Открытие — явное действие
  пользователя, как и подключение к облаку.
- Не писать в папку игры. Копия сохраняется туда, куда указал пользователь.
- В вебе этой вкладки нет: браузер не имеет доступа к файловой системе.
  Отсутствие показать честно, а не прятать.

## Проверка

- Фальшивое дерево с тремя слотами → три строки, порядок по времени.
- Файл, который не распознан ни одним форматом → показан с пометкой, открытие
  даёт понятную ошибку.
- Папка исчезла между обновлением и открытием → ошибка, не падение.
- `make check`, `make test`.

## Результат — 2026-09-15

- Реализовано в коммите `dc094b4` на ветке `codex/m04-save-slots`.
- Создан отдельный [PR #51](https://github.com/Dmitriy-DE/S.T.A.L.K.E.R.-2-HoC---Save_Editor/pull/51).
- В Qt добавлена асинхронная read-only вкладка «Найденные сейвы»: она
  перечисляет `.sav`, показывает имя, размер, время изменения и формат,
  определённый по содержимому. Кандидатные пути M03 сохраняются в результате
  поиска и видны пользователю даже при пустом списке.
- Неизвестный `.sav` остаётся в таблице с честной пометкой и при явном
  открытии проходит существующий общий `FormatDetectionError`; исчезнувший
  файл превращается в обычную ошибку чтения. Автоматического открытия и
  записи в игровые каталоги нет; ручный file picker сохранён.
- Проверки: `PYTHON=.venv/bin/python make check` — exit 0;
  `PYTHON=.venv/bin/python make test` — exit 0, 187 passed.
- Не проверено: реальные сейвы X-Ray, Windows/Proton runtime и загрузка в
  игре; браузерная вкладка намеренно не добавлялась.
