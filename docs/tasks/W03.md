# W03 — Публикация веб-версии

**Зависимости:** W02. **Gate:** release. **Priority:** P3.

## Scope

- Статическая сборка на GitHub Pages из того же тега, что и десктопные пакеты.
- Заголовки `Cross-Origin-Opener-Policy`/`Cross-Origin-Embedder-Policy`, если
  понадобится `SharedArrayBuffer`; проверить, что Pages их отдаёт, иначе
  выбрать вариант загрузки WASM без них.
- В подвале страницы: версия, commit, ссылка на десктопные сборки и явная
  строка о том, что файл не покидает браузер.
- Проверка на живом URL в Chrome и Firefox на реальном сейве.

## Критерий приёмки

Открытая ссылка читает сейв, показывает деньги и инвентарь и отдаёт корректную
изменённую копию. Цифры сверяются с десктопом на том же файле.
