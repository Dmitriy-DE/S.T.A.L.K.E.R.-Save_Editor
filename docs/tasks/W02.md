# W02 — Веб-интерфейс поверх общего ядра

**Зависимости:** W01. **Gate:** code. **Priority:** P2.

## Границы

Веб-версия работает **только с локальными файлами**. Steam Cloud остаётся
десктопным: helper — это отдельный процесс на машине пользователя, из вкладки
браузера его не запустить. Честно написать это в интерфейсе, а не прятать
неработающую вкладку.

Сейв никуда не загружается. Страница статическая, сервера нет, файл читается
через File System Access API (или `<input type=file>` как запасной путь для
браузеров без него) и сохраняется скачиванием. Это не только про приватность:
проект держится на том, что исходный файл не меняется, а правка уходит в
новую копию — то же правило остаётся и в вебе.

## Scope

- Экраны: открытие файла, обзор с теми же parser-backed метаданными, инвентарь
  с поиском и фильтрами, staged-изменения, preview, сохранение копии.
- Та же Zone-палитра, что в Qt: один визуальный язык, общий источник токенов.
- Бэкапы: в браузере нет папки бэкапов, поэтому вместо журнала — обязательное
  «сохрани исходник рядом» до применения правок.

## Чего не делать

Аккаунтов, синхронизации, серверного хранения. Если появится сервер — появятся
чужие сейвы на чужом диске, и весь разговор про безопасность правок
превращается в разговор про хостинг.
