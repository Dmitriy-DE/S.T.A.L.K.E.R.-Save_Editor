## Реализация и evidence

`tests/conftest.py` содержит отдельный 64-byte object-record builder и fixture
без личных байтов. В fixture два visible объекта и два orphan-кандидата; один
visible stack имеет count=2 и total weight=0.2, второй — count=1. `tests/test_save_baseline.py`
содержит 9 тестов, включая negative cases.

Красная фаза: запуск до добавления fixture завершился 9 ошибками `fixture
'synthetic_save' not found`. Зелёная фаза и итоговый suite:

```text
python3 -m pytest tests/test_save_baseline.py -v   -> 9 passed
make test                                           -> 9 passed
make check                                          -> exit 0
make selftest SAVE=<private-D639>                   -> exit 0
```

Изменены только `tests/conftest.py`, `tests/test_save_baseline.py`,
`requirements-dev.txt` и `Makefile`; runtime parser/decoder/cloud code не
менялся. Тесты доказывают контракт parser на synthetic bytes и сохранение
известных инвариантов. Они не доказывают Windows, Steam Cloud или игровую
семантику.
