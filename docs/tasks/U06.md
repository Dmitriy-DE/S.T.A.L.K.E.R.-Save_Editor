Это planned paths: создаются в этой задаче или её зависимостях; команды ниже не являются уже существующим/пройденным test suite. Не менять соседние подсистемы ради cleanup. Если обнаружена необходимость изменения контракта, сначала описать его в карточке и spec, не молча переименовывать API.

UI не вызывает Steam/helper при создании окна. Cloud operations принимают
инжектируемый service/transport, а выбранный remote path и SHA остаются частью
immutable `SourceRef`/`PreparedEdit`.

## Вход и выход

UI отображает CloudReceipt.status/reason; selected cloud path закреплён в SourceRef. Никаких Steam writes при открытии приложения.
