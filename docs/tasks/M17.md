# M17 — Улучшения оружия и экипировки X-Ray

**Зависимости:** M10, M11. **Gate:** research → code. **Priority:** P2.

## Scope

Для официальных оригинальных Clear Sky и Call of Pripyat показать и изменить
список улучшений, записанный в inventory object. Операция ограничена точным
`m_upgrades` vector конкретного предмета: add, remove и clear меняют порядок и
содержимое этого списка, не переписывая соседние поля.

Shadow of Chernobyl остаётся read-only: подтверждённого vector в его версии
STATE нет. S.T.A.L.K.E.R. 2 и Enhanced Editions этим изменением не открываются.
Моды и их каталоги не входят в scope.

## Подтверждённая схема

Исходник OpenXRay `CSE_ALifeInventoryItem::STATE_Read/STATE_Write` связывает
`m_upgrades` с version boundary `m_wVersion > 123`; сериализация — `u32 count`
и нулевые строки. Каталог новых ID берётся из официальных ресурсов выбранного
release и дополнительно проверяется на применимость к exact `type_key`.

Уже существующий ID, отсутствующий в каталоге, не объявляется мусором: его
можно оставить или удалить, но добавить такой ID заново нельзя. Пустой vector
разрешён для явного Clear.

## UI и безопасность

- Qt и web показывают текущие значения, официальные варианты и неизвестные
  сохранённые ID; изменения сначала staged.
- Preview/Download не меняет исходный файл. Desktop replacement использует
  обязательный M16 backup и read-back; браузер предлагает только новую копию.
- Список изменений помечает upgrades как опасную поведенческую правку.
- При отсутствии подтверждённого vector, каталога, release capability или
  applicability поле остаётся read-only.

## Результат — 2026-09-16

Структурный parser/writer, Qt/web staging и round-trip проверки реализованы.
Read-only probe официального корпуса дал: SoC — 0 vectors; CS — 75 vectors,
3 непустых, 7 сохранённых ID совпали с каталогом и 9 не совпали; CoP — 132
vectors, 3 непустых, 38 сохранённых ID совпали и неизвестных не найдено.
Подробности: [XRAY_UPGRADES](../evidence/XRAY_UPGRADES_2026-09-16.md).

Эти числа относятся к конкретным локальным слотам. Игра не запускалась, сейвы
не перезаписывались, поэтому M10 game load/re-save и подтверждение поведения
upgrade-меню остаются открытыми.
