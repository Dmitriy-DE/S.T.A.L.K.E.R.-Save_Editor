## Вход и выход

`python -m ui` запускает Qt app. `MainWindow` принимает `EditorService`; локальный analyze выполняется в worker, результаты приходят через signals. Старый `app.py` остаётся fallback.

## Реализация и локальное evidence

`ui/__init__.py`, `ui/__main__.py`, `ui/main_window.py` и
`requirements-ui.txt` добавляют pinned `PySide6==6.11.2`, `pytest-qt==4.5.0`
и `requirements-dev.txt`. `MainWindow(EditorService)` выполняет local
read/inspect в `InspectWorker(QThread)`, а immutable `LocalSnapshot` и
`analysis_ready`/`analysis_failed` signals возвращаются в UI thread. Ошибка
malformed-файла оставляет последний корректный snapshot и его сводку.

Красная фаза: до установки UI dependencies `tests/test_ui_open.py` был
пропущен с pytest exit 5; после добавления модулей и pinned dependencies:

```text
QT_QPA_PLATFORM=offscreen /tmp/save-editor-ui-venv/bin/python -m pytest tests/test_ui_open.py -v -> 2 passed
/tmp/save-editor-ui-venv/bin/python -m pytest tests -q                                     -> 72 passed
/tmp/save-editor-ui-venv/bin/python -m py_compile app.py cli.py save_format.py steam_cloud.py ui/__main__.py ui/main_window.py -> exit 0
Qt startup smoke (offscreen)                                                        -> exit 0
git diff --check                                                                    -> exit 0
```

Это synthetic/offscreen Linux evidence. Native Windows startup, screenshots,
DPI 1366×768/150–200% и editing parity остаются отдельными gates; P03
GitHub runner evidence также не закрыт.
