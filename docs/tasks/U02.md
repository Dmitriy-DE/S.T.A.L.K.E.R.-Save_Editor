## Реализация и локальное evidence

Добавлены `ui/__init__.py`, `ui/__main__.py`, `ui/main_window.py` и
`requirements-ui.txt` с pinned `PySide6==6.11.2`, `pytest-qt==4.5.0` и
`requirements-dev.txt`. `python -m ui` запускает Qt shell, а
`MainWindow(EditorService)` выполняет local read/inspect в отдельном
`InspectWorker(QThread)`. Immutable `LocalSnapshot` и `analysis_ready` /
`analysis_failed` signals возвращаются в UI thread. Последний корректный
snapshot сохраняется при malformed-файле; preview/save actions отключены до
первого успешного анализа.

Красная фаза: до установки UI dependencies `tests/test_ui_open.py` был
пропущен (PySide6 отсутствовал, pytest exit 5); после добавления модулей и
установки pinned dependencies:

```text
QT_QPA_PLATFORM=offscreen /tmp/save-editor-ui-venv/bin/python -m pytest tests/test_ui_open.py -v -> 2 passed
/tmp/save-editor-ui-venv/bin/python -m pytest tests -q                                     -> 72 passed
/tmp/save-editor-ui-venv/bin/python -m py_compile app.py cli.py save_format.py steam_cloud.py ui/__main__.py ui/main_window.py -> exit 0
Qt startup smoke (offscreen)                                                        -> exit 0
git diff --check                                                                    -> exit 0
```

Это synthetic/offscreen Linux evidence. Native Windows startup, screenshots,
DPI 1366×768/150–200% и editing parity остаются отдельными gates; P03
GitHub runner evidence также не закрыт.

## Реализация и локальное evidence

Добавлены `ui/__main__.py`, `ui/main_window.py` и pinned
`requirements-ui.txt` (`PySide6==6.11.2`, `pytest-qt==4.5.0`). `MainWindow`
принимает `EditorService`; `InspectWorker` выполняет чтение и inspect в
QThread, а immutable `LocalSnapshot` и signals возвращаются в UI thread.
Shell содержит вкладки «Обзор», «Инвентарь», «Изменения» и «Резервные копии»,
responsive table, loading/error states и disabled preview/save actions до
первого успешного анализа. Ошибка malformed файла оставляет предыдущий
snapshot и его сводку.

Красная фаза: до добавления UI-модуля тесты не могли импортировать
`PySide6/ui.main_window`; после установки pinned UI dependencies:

```text
QT_QPA_PLATFORM=offscreen /tmp/save-editor-ui-venv/bin/python -m pytest tests/test_ui_open.py -v -> 2 passed
python3 -m pytest tests -q                                                                        -> 70 passed (core environment)
make check                                                                                         -> exit 0
```

Qt tests используют только synthetic fixture и offscreen backend. Native
desktop startup, DPI 1366×768/150–200% и Windows UI остаются ручным evidence
gate; P03 GitHub runner blocker также не закрыт.
