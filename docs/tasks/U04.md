## Границы изменения

- `ui/changes_view.py`
- `ui/operation_worker.py`
- `ui/main_window.py`
- `tests/test_ui_apply.py`

`MainWindow` остаётся единственным UI-thread orchestrator; worker получает
только immutable `EditPlan`/`PreparedEdit` и bytes. Local export делегируется
`EditorService.export_local`, поэтому backup, atomic publish и stale-SHA
проверяются общим storage-кодом.

## Вход и выход

Preview хранит `PreparedEdit` и immutable `EditPlan`; apply использует тот же
`PreparedEdit`, исходный SHA и source bytes. Любое изменение staged формы
сбрасывает preview. До preview output не создаётся.

## Красная фаза и отладка

До создания модулей `tests/test_ui_apply.py` не собирался с отсутствующим
`QCloseEvent`/preview API. После исправления импорта тест double-click сначала
показал Qt abort при teardown: fake export ещё выполнялся, а `qtbot` уничтожал
родительский QThread после получения result signal. Ожидание `finished` в
регрессионном тесте подтвердило root cause; production guard `closeEvent`
теперь игнорирует закрытие во время операции, а controls отключены до
завершения worker.

## Реализация и evidence

`OperationWorker` выполняет preview (`service.prepare`) или apply
(`service.export_local`) в QThread, проверяет тип `PreparedEdit`, передаёт
progress/error signals и не читает Qt widgets. `ChangesView` показывает
staged rows, before→after, output destination, preview output size/SHA,
backup receipt и disabled Steam action. `MainWindow` строит `EditPlan` из
текущего snapshot, инвалидирует preview при изменении money/stack, блокирует
двойной запуск и отклоняет plan, если форма или source SHA устарели.

## Ограничения и packaging note

U04 не добавляет новые binary dependencies. Ядро и storage используют
стандартную библиотеку; `pyooz` остаётся необходимым decoder runtime, PySide6
нужен только Qt UI, pytest/pytest-qt — dev/test. Позже B01 должен вкладывать
эти runtime-компоненты в standalone Windows `.exe` и Debian/Ubuntu `.deb` плюс
portable Linux archive, чтобы конечному пользователю не требовались Python и
pip. SteamCloudFileManager остаётся отдельным helper до проверки его
redistribution/ABI/protocol.
