# M06 — Corpus и формат evidence для чужого формата

**Зависимости:** M01. **Gate:** research. **Priority:** P2.

## Зачем

Без контролируемых сейвов реверс превращается в угадывание. Эта карточка
готовит метод, а не парсер.

## Scope

Для каждой новой игры собрать корпус: серия сохранений, где между ними менялась
**ровно одна** вещь (потратил патроны, подобрал предмет, изменились деньги), с
записанным действием и хэшами файлов.

Формат отчёта: что менялось, какие байты сдвинулись, какие кандидаты отвергнуты
и почему, на скольких файлах воспроизводится.

Личные сейвы в репозиторий не попадают — только хэши, смещения и выводы.

## Критерий

Поле считается найденным, если: воспроизводится минимум на трёх независимых
парах, правка даёт ожидаемый результат в самой игре, и обратная правка
возвращает исходное поведение. Одно совпадение — это совпадение.

## Проверка

Отчёт в `docs/evidence/`, воспроизводимый по описанию другим человеком.
Нет доказательств — статус `blocked`, зависимые карточки не начинаются.
