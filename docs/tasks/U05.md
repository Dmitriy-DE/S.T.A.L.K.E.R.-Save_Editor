## Stop conditions

Недоступные личные данные, непрошедший dependency gate или неизвестный формат не заменять догадкой. Записать BLOCKED и конкретные missing inputs. Для research gate отчёт с неопровергнутыми кандидатами не открывает зависимую mutating-задачу. Тестирование реального cloud/game выполняется только по отдельному поручению владельца.
