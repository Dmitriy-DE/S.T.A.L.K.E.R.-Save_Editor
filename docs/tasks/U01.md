## Реализация и evidence

`editor/service.py` теперь является единой UI-free точкой оркестрации для
`inspect`, `prepare`, `export_local` и `upload_cloud`. Production parser,
immutable prepare, atomic local storage и fail-closed cloud transaction
передаются через конструктор как injectable callables; это позволяет Qt/Tk/CLI
использовать одни и те же правила и fake transport в тестах. Tk и CLI вызывают
service вместо прямого импорта writer/parser orchestration, их команды и
подтверждения сохранены.

Красная фаза: до создания `editor/service.py` collection завершался
`ModuleNotFoundError: No module named 'editor.service'`. После реализации:

```text
python3 -m pytest tests/test_service_parity.py tests/test_storage.py tests/test_cloud_transaction.py -v -> 19 passed
python3 -m pytest tests -q                                                                        -> 70 passed
make check                                                                                         -> exit 0
python3 cli.py info "$XDG_DATA_HOME/Stalker2SaveEditor/private-import-2026-09-19/D639C0F24C64FC164326E8967A8DCCBE.sav" -> exit 0
git diff --check                                                                                    -> exit 0
```

CLI smoke использовал только локальный приватный сейв из `.local`, который
остается вне Git; новые parity tests работают на synthetic fixture. Service
не импортирует Tkinter, PySide или PyQt. Live Steam/GFN и Windows UI smoke
по-прежнему отдельные gates.
