## Runner gate: причина startup_failure и исправление (2026-09-14)

Пять запусков завершались `startup_failure` без создания jobs. YAML обоих
workflow разбирается корректно, поэтому синтаксис исключён. Оставшаяся
кандидатная причина в коде репозитория — метки runner: matrix называла
`ubuntu-22.04` и `windows-2022`, образы, снятые GitHub с обслуживания.
Нерезолвимая метка отклоняет run на этапе startup, до появления jobs, что
совпадает с наблюдаемой картиной.

Изменено:

- `test.yml` и `build.yml` переведены на `ubuntu-24.04` / `windows-2025`;
- `tests/test_ci_contract.py` запрещает retired-метки в обоих workflow
  (`test_every_workflow_names_a_hosted_runner_image`), чтобы та же ошибка не
  вернулась незамеченной;
- `packaging/build.py` больше не зашивает `Depends: libc6 (>= 2.35)`: минимум
  вычисляется из glibc build host и записывается в `BUILD_MANIFEST.json`
  (`libc_minimum`). На 24.04 runner `.deb` честно требует glibc 24.04.

Следствие для платформенного заявления: собранный на `ubuntu-24.04` `.deb`
**не** является артефактом для Ubuntu 22.04. Если 22.04 остаётся целью beta,
нужен отдельный container-build (`container: ubuntu:22.04` поверх hosted
runner); это не входит в текущую правку и не заявляется сделанным.

Гейт остаётся открытым до фактического зелёного run: локально проверить
доступность образов нельзя. Если после смены меток run снова падает без jobs,
следующая проверка — Settings → Actions (Actions выключены / ограничены
политикой) и billing, а не файлы workflow.

Локальная проверка правки:

```text
python3 -m pytest tests -q -> 84 passed, 6 skipped
```

## Статус 2026-09-14: blocked, гейт снят с критического пути

Владелец сообщил, что GitHub Actions ему недоступны. Метки runner исправлены и
контрактный тест их сторожит, но зелёного прогона в этом репозитории ждать
неоткуда, поэтому карточка переведена в `blocked`, а не держит очередь.

Гейтом качества считается локальный прогон: `make check` (lint, typecheck,
docs/web drift, компиляция) и `make test`. Если Actions когда-нибудь включат,
workflow лежит готовым и запускается без изменений.
