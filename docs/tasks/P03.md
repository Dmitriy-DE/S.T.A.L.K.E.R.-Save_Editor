## Реализация и локальное evidence

`.github/workflows/test.yml` запускает четыре обязательные комбинации
`ubuntu-22.04/windows-2022 × Python 3.11/3.12` с `contents: read`, без
`continue-on-error`. Каждая job устанавливает pinned `pyooz==0.0.8` и
`pytest==9.0.2`, проверяет отсутствие `.local`, `*.sav` и `*.bak`, компилирует
исходники и запускает полный suite. При ошибке сохраняются только JUnit и
sanitized pytest log в artifact; Steam credentials и cloud writes в workflow
не используются.

Красная фаза контрактного теста: до создания workflow три теста завершались
`FileNotFoundError: .github/workflows/test.yml`. После реализации:

```text
python3 -m pytest tests/test_ci_contract.py -q -> 3 passed
python3 -m pytest tests -q                  -> 67 passed
python3 -m py_compile ...                   -> exit 0
git diff --check                            -> exit 0
```
