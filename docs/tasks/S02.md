## Реализация и evidence

Добавлены `editor/models.py` с frozen `SourceRef`, `EditPlan` и `PreparedEdit`,
а также `editor/prepare.py` с единой проверкой исходного SHA и вызовом
существующего `patch_save`. План нормализует staged-коллекции в tuples до
запуска worker; поэтому изменения Tk-словарей после подтверждения не меняют
операцию. `prepare_edit` отклоняет raw вместе с `detach` или `attach` до
вызова `patch_save`, но сохраняет raw-only и detach-only сценарии.

Красная фаза: до создания пакета `editor` сбор тестов завершился
`ModuleNotFoundError: No module named 'editor'`. После реализации:

```text
python3 -m pytest tests/test_edit_plan.py -v                -> 7 passed
make test                                                   -> 16 passed
make check                                                  -> exit 0
python3 -m py_compile editor/__init__.py editor/models.py editor/prepare.py -> exit 0
make selftest SAVE=.local/original-import-2026-09-13/D639C0F24C64FC164326E8967A8DCCBE.sav -> exit 0
```

Private-corpus self-test подтвердил прежние structural/container инварианты;
байты личного сейва не добавлялись в Git. Новые тесты проверяют stale SHA,
неизменяемость снимка, запрет опасного batch и verified output SHA. Проверка
Windows, Steam Cloud и игровой семантики в этой карточке не выполнялась.
