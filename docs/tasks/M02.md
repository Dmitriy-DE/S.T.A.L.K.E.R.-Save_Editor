# M02 — Определение игры по файлу и честный отказ

**Зависимости:** M01. **Gate:** code. **Priority:** P1.

## Зачем

Пользователь кидает произвольный `.sav`. Программа обязана либо назвать игру,
либо сказать «не знаю этот формат» — и ни в коем случае не пытаться разобрать
чужой файл сигнатурой S.T.A.L.K.E.R. 2.

## Scope

- `detect(data)` по реестру: каждый формат смотрит только свою сигнатуру и не
  бросает исключений на чужих байтах.
- Понятная ошибка при промахе: что открыли, сколько весит, почему не подошло,
  какие форматы поддерживаются сейчас.
- Ошибка одинаковая в Qt, CLI и вебе — текст живёт в ядре, не в интерфейсах.

## Негативные сценарии, обязательные к покрытию

Пустой файл, обрезанный файл, файл с верным размером и мусором внутри,
сейв другой игры (использовать любой заведомо чужой бинарник), текстовый файл
с расширением `.sav`.

## Чего не делать

Не определять игру по имени файла или расширению: и то и другое пользователь
меняет. Только содержимое.

## Проверка

- На каждый негативный сценарий — отказ с указанием причины, без traceback.
- Исходный файл не изменяется ни в одном из сценариев.
- `make check`, `make test`.
