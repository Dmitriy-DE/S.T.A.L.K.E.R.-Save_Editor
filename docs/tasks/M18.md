# M18 — Локальный Support project UI

**Зависимости:** M17. **Gate:** code. **Priority:** P3.

## Scope

Добавить небольшую кнопку `♡ Support project` в верхнюю правую часть Qt title
bar и web header. Нажатие открывает локальный диалог с ровно тремя способами
поддержки:

- PayPal — `breygel.dima@gmail.com`;
- Binance Pay — `Binance ID: 434350727`;
- USDT — `Network: TRON (TRC20)`, `Address:`
  `TF5hpkAmF9vjbpaRpJ5ewpbCC122jED1ds`.

У каждого значения есть рабочая кнопка `Copy` и краткий feedback `Copied`.
Диалог не открывает платёжный provider напрямую.

## Границы

Никаких payment API, backend, authentication, tracking, analytics, QR-кодов,
startup popups или повторяющихся напоминаний. Web остаётся полностью локальным;
Qt использует `QDialog` и application-modal `open()` без отдельного потока.
Непр unrelated functionality не меняется.

## Визуальное решение

За основу взяты элементы пользовательского X-Ray референса
[stalker-new-arsenal-7-spawner](https://github.com/thinkawitch/stalker-new-arsenal-7-spawner):
компактные верхние controls, тёмные рамки, rust/gold/sand состояния и
иерархия `method → value → action`. Реальные игровые шрифты, `.dds` и UI XML
не копируются; реализация использует существующие Qt QSS и web CSS.
Подробности: [UI_SUPPORT](../evidence/UI_SUPPORT_2026-09-16.md).

## Результат — 2026-09-16

Qt `SupportDialog` показывает значения в read-only полях, копирует каждый value
в clipboard и восстанавливает кнопку после `Copied`. Web использует
lightweight `<dialog>` с тем же содержимым, native clipboard и textarea fallback
для старых браузеров. Исходный редактор, сейвы и любые сетевые состояния не
затрагиваются.
