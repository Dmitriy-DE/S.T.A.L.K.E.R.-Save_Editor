## Вход и выход

Новый optional rebuild mode сохраняет исходные compressed blocks только при доказанных block boundaries/dependencies. Всегда доступен текущий deterministic full rebuild.

## Приёмка

- python -m pytest tests/test_compact_rebuild.py -v
- Unsupported stream → valid full rebuild; compact/raw bytes identical after decompress; game acceptance отдельно.

## Stop conditions

Недоступные личные данные, непрошедший dependency gate или неизвестный формат не заменять догадкой. Записать BLOCKED и конкретные missing inputs. Для research gate отчёт с неопровергнутыми кандидатами не открывает зависимую mutating-задачу. Тестирование реального cloud/game выполняется только по отдельному поручению владельца.
