# M16 — Запись в папку игры с резервной копией и восстановлением

**Зависимости:** M10. **Gate:** code. **Priority:** P2.

## Зачем

Сейчас правка всегда уходит в новую копию, и это правильное поведение по
умолчанию. Но чтобы редактор был удобным, пользователю нужно сохранять прямо в
папку сохранений игры — иначе он будет копировать файлы руками и рано или
поздно перепутает.

## Scope

Для десктопа: запись в выбранный слот в папке игры, с обязательным порядком:

1. резервная копия исходного файла с проверяемым хэшем;
2. запись во временный файл рядом;
3. атомарная замена;
4. перечитывание записанного и сверка.

Резервные копии видны в журнале и восстанавливаются — механизм уже есть для
S.T.A.L.K.E.R. 2, распространить на трилогию.

Восстановление возвращает слот в исходное состояние в один шаг: пользователь,
который сломал сейв, должен иметь возможность откатиться без файлового
менеджера.

## Границы

- Замена в папке игры — **явное** действие, а не поведение по умолчанию.
- Не писать, пока игра запущена, если это определимо: предупредить.
- В браузерной версии этого нет и быть не может; показать честно.

## Проверка

- Запись и откат на фальшивом дереве папок.
- Прерванная запись не оставляет повреждённый слот.
- Резервная копия с несовпадающим хэшем не предлагается для восстановления.
- `make check`, `make test`.
