## Реализация и evidence

`editor.platforms` добавляет единые пути: Linux использует
`XDG_DATA_HOME` или `~/.local/share`, Windows — `%APPDATA%`, затем
`%LOCALAPPDATA%`. `legacy_data_dir()` и `backup_dirs()` оставляют старый
`~/Stalker2SaveEditor` доступным для чтения; приложение читает legacy config,
пишет новые настройки и backups только в текущий каталог, без удаления или
автоматического переноса старых файлов. CLI использует тот же default backup
path.

`discover_helper()` принимает `STALKER2_STEAM_HELPER`, PATH и ограниченные
platform-specific release locations. Linux проверяет execute bit, Windows
выбирает `.exe` независимо от POSIX mode bits. `SteamWorker` запускает
`[helper, "--steam-worker"]` с `shell=False` и не меняет mode `.exe`. Новый
`run.bat` использует Python launcher на Windows; `run.sh` принимает
`PYTHON_BIN` и корректно работает из каталога с пробелами.

Красная фаза: до создания `editor/platforms.py` тесты завершались на
`ModuleNotFoundError: No module named 'editor.platforms'`. После реализации:

```text
python3 -m pytest tests/test_platforms.py -v        -> 10 passed
python3 -m pytest tests/test_worker_lifecycle.py -q  -> 7 passed
make test                                           -> 56 passed
make check                                          -> exit 0
bash -n run.sh                                      -> exit 0
```

Протокол helper сверён с upstream `v1.3.5`; details находятся в
[`docs/evidence/HELPER_COMPATIBILITY.md`](../evidence/HELPER_COMPATIBILITY.md).
Реальный binary/Ping на Windows, Steam connect и cloud sync не запускались в
текущем Linux окружении; это остаётся P03/S06/manual evidence.
