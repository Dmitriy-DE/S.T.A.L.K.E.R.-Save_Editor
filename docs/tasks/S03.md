## Вход и выход

export_local(source_path: Path, output_path: Path, prepared: PreparedEdit, backup_dir: Path) -> ExportReceipt. По умолчанию output не существует и не равен source. Backup UUID/exclusive, prepared.plan.source SHA проверяется свежим read.
