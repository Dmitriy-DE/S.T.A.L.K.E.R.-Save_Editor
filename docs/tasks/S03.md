## Вход и выход

export_local(source_path: Path, output_path: Path, prepared: PreparedEdit, backup_dir: Path) -> ExportReceipt. По умолчанию output не существует и не равен source. Backup UUID/exclusive, prepared.plan.source SHA проверяется свежим read.

## Реализация и evidence

`editor/storage.py` добавляет `export_local` с проверкой local `SourceRef`,
свежим чтением исходника, UUID/exclusive backup, журналом JSON и временным
файлом в каталоге назначения. Публикация выполняется через `os.link` с
атомарным `EEXIST`-барьером, затем output читается обратно и сверяется по SHA.
Ошибки backup, временной записи, журнала и гонки существующего output не
возвращают receipt; временный файл удаляется, backup остаётся для восстановления.

CLI сохраняет существующие команды, строит `EditPlan`/`PreparedEdit` и вызывает
тот же storage; у mutating-команд появился `--backup-dir`. Tk local apply также
использует storage, а cloud path сохраняет прежнюю отдельную транзакцию до S06.

Красная фаза: до реализации `editor.storage` тесты завершились
`ModuleNotFoundError: No module named 'editor.storage'`. После реализации:

```text
python3 -m pytest tests/test_storage.py tests/test_edit_plan.py -v -> 15 passed
make test                                                     -> 24 passed
make check                                                    -> exit 0
python3 -m py_compile app.py cli.py editor/storage.py           -> exit 0
CLI smoke: set-money + info                                  -> exit 0
CLI existing-output guard                                    -> exit 2, output unchanged
```

Тесты fault-inject backup/temp/journal, stale source, same-path, existing
output, Unicode paths, UUID uniqueness и no-overwrite race. GUI/Windows и
реальный Steam Cloud не запускались; hard-link publish при неподдерживаемой
файловой системе завершает операцию ошибкой вместо перезаписи.
