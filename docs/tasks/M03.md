# M03 — Поиск Steam и папок сохранений

**Зависимости:** M01. **Gate:** code. **Priority:** P1.

## Scope

Расширить `editor/platforms.py` (не заводить второй модуль путей):

- `steam_roots()` — корни Steam. Windows: реестр `HKCU\Software\Valve\Steam` →
  `SteamPath`, затем `%ProgramFiles(x86)%\Steam`. Linux: `~/.steam/steam`,
  `~/.local/share/Steam`, Flatpak-путь.
- `steam_libraries()` — разбор `steamapps/libraryfolders.vdf`. Формат текстовый,
  парсится своим кодом; **внешних зависимостей не добавлять**.
- `installed_game(app_id)` — по `appmanifest_<appid>.acf` в каждой библиотеке.
- `save_directories(game_id)` — каталоги сохранений для игры, все найденные.

**Proton обязателен.** На Linux игры серии идут через Proton, и сейвы лежат
внутри префикса: `<library>/steamapps/compatdata/<appid>/pfx/drive_c/users/steamuser/...`.
Поиск, который это не учитывает, на Linux не найдёт ничего.

## Контракт

Все функции принимают инъектируемые `environ`, `home` и корень файловой
системы, как уже сделано в `discover_helper`. Тесты собирают фальшивое дерево в
`tmp_path` и проверяют обе ОС на любой машине — CI гоняет Linux и Windows.

Ничего не пишем и не создаём: только чтение и перечисление.

## Проверка

- Steam не установлен → пустой результат, не исключение.
- `libraryfolders.vdf` битый → пропускается с предупреждением, остальные
  библиотеки работают.
- Библиотека на другом диске → найдена.
- Proton-префикс → найден на Linux.
- Симлинк, ведущий наружу дерева → не раскрывается молча.
- `make check`, `make test`.
