# M03 — Где лежат сохранения: исследование и поиск

**Зависимости:** M01. **Gate:** research → code. **Priority:** P1.

## Зачем

Игр четыре, изданий у каждой несколько, launcher'ов три, плюс Linux через
Proton. Путь «Documents\STALKER-SHOC\savedgames» покрывает меньше половины
реальных установок. Эту карточку нельзя сделать по памяти — нужно найти и
проверить.

## Часть 1: исследование (обязательна до кода)

Найти и **записать в `docs/evidence/SAVE_LOCATIONS.md`** пути сохранений для
каждой комбинации:

| Игра | Издания, которые надо покрыть |
|---|---|
| S.T.A.L.K.E.R. 2: Heart of Chornobyl | Steam, Game Pass/Microsoft Store, GOG |
| Shadow of Chernobyl | оригинал (диск/патчи 1.0004–1.0006), Steam, GOG, Legends of the Zone Trilogy, Enhanced Edition |
| Clear Sky | оригинал (1.5.10), Steam, GOG, Legends of the Zone Trilogy, Enhanced Edition |
| Call of Pripyat | оригинал (1.6.02), Steam, GOG, Legends of the Zone Trilogy, Enhanced Edition |

Для каждой строки записать: точный путь с переменными окружения, откуда взято
(ссылка), и как проверено. Отдельно отметить, где путь зависит от языка системы
(папка «Мои документы» локализуется) и где он лежит внутри `Saved Games`, а не
`Documents`.

Полезные источники: PCGamingWiki (у каждой игры есть раздел Save game data
location с разбивкой по изданиям), вики модов, конфиги самих игр
(`fsgame.ltx` в X-Ray задаёт корень пользовательских данных и его можно
переопределить — это тоже надо учесть).

**Не выдумывать пути.** Строка без источника в отчёт не попадает.

## Часть 2: код

Расширить `editor/platforms.py` (не заводить второй модуль путей):

- `steam_roots()` — Windows: реестр `HKCU\Software\Valve\Steam` → `SteamPath`,
  запасной `%ProgramFiles(x86)%\Steam`. Linux: `~/.steam/steam`,
  `~/.local/share/Steam`, Flatpak `~/.var/app/com.valvesoftware.Steam/data/Steam`.
- `steam_libraries()` — разбор `steamapps/libraryfolders.vdf` своим кодом,
  **без новых зависимостей**. Формат текстовый и вложенный, битый файл
  пропускается с предупреждением.
- `gog_roots()`, `xbox_roots()` — по тем же правилам, если исследование
  показало, что они нужны.
- `installed_games()` — какие игры серии реально установлены, по манифестам
  `appmanifest_<appid>.acf` и по наличию каталогов.
- `save_directories(game_id)` — все найденные каталоги сохранений для игры.

**Proton обязателен.** На Linux игры серии идут через Proton, и «Мои документы»
лежат внутри префикса:
`<library>/steamapps/compatdata/<appid>/pfx/drive_c/users/steamuser/Documents/...`.
Поиск без этого на Linux вернёт пусто.

`fsgame.ltx`: если он найден рядом с игрой и переопределяет `$game_saves$`,
уважать его.

## Контракт

Все функции принимают инъектируемые `environ`, `home` и корень файловой
системы, как уже сделано в `discover_helper`. Тесты собирают фальшивое дерево в
`tmp_path`, поэтому обе ОС проверяются на любой машине. Ничего не создаём и не
пишем: только чтение и перечисление.

## Проверка

- Steam/GOG не установлены → пустой результат, не исключение.
- Библиотека на другом диске → найдена.
- Proton-префикс → найден на Linux.
- Локализованная папка документов → найдена.
- `fsgame.ltx` с переопределением → учтён.
- Битый `libraryfolders.vdf` → пропущен, остальные библиотеки работают.
- `make check`, `make test`.
