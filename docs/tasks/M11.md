# M11 — Каталоги игры: предметы, группировки, идентификаторы

**Зависимости:** M06. **Gate:** code. **Priority:** P1.

## Зачем

Предметы, группировки и их идентификаторы у трёх игр разные. На каталоге
предметов это уже видно: 389 / 417 / 434 записи, общих 261. С группировками
будет так же — в Чистом Небе есть сама Чистое Небо и ренегаты, в Зове Припяти
зомбированные, состав и имена не совпадают.

## Scope

Расширить существующий каталог, который уже читает предметы из ресурсов
установленной игры:

- **группировки**: идентификатор, отображаемое имя, к какой игре относится;
- **идентификаторы**, нужные для правок: как называется сообщество актёра, как
  адресуются отношения между сообществами;
- **отображаемые имена предметов и группировок** на языке игры, если они есть
  в ресурсах.

Всё читается из ресурсов конкретной установленной игры. Списка, вписанного
руками, в коде быть не должно ни одного.

## Контракт

Каталог знает, для какой игры он собран, и не смешивает данные разных игр.
Запрос группировки, которой в этой игре нет, даёт явный отказ, а не пустое
значение.

## Проверка

- Каталоги трёх игр отличаются составом; пересечение не равно ни одному из них.
- Группировка из Чистого Неба не находится в каталоге Тени Чернобыля.
- Игра не установлена → пустой каталог и понятное сообщение, не исключение.
- Веб-сборка получает те же данные, что десктоп, без игровых архивов и путей.
- `make check`, `make test`.
