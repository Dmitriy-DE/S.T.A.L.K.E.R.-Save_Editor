# Документация

## Актуальные документы

- [STATUS](STATUS.md): проверенный baseline, ограничения и привязка к задачам.
- [Спецификация](specs/CROSS_PLATFORM_EDITOR.md): продукт, платформы, архитектура, UI.
- [ROADMAP](plans/ROADMAP.md): очередность и release gates.
- [Задачи](tasks/INDEX.md): отдельный файл и GitHub issue на каждый результат.
- [LUNA_HANDOFF](LUNA_HANDOFF.md): инструкция исполнителю.
- [RELEASE](RELEASE.md): сборка, тестирование, публикация.
- [IMPORT](IMPORT.md): откуда взялись файлы и что сохранено локально.
- [SAVE_FORMAT](SAVE_FORMAT.md): известные поля; применимость ограничена контрольными сейвами.
- [EXPERIMENTAL](EXPERIMENTAL.md): смысл операций, не доказанный игровой результат.
- [Evidence baseline](evidence/BASELINE_2026-09-13.md): текущая проверка.

Статусы карточек: `waiting_dependencies` ждёт принятый входной gate,
`in_progress` выполняется на ветке, `in_review` имеет открытый PR, а
`accepted` означает слитый PR с записанными проверками. GitHub issue и PR в
карточке являются ссылками на фактическую историю, а не заменой локального
evidence.

## История

[history/](history/) содержит прежний README, Codex prompt и handoff v0.3. Это снимки старых утверждений, не текущие инструкции. [Research notes](../NOTES_FROM_RESEARCH.md) сохраняют предыдущие гипотезы; внешние ссылки в старых заметках не означают свежую проверку. Полная персональная история находится только в локальном архиве.

При противоречии руководствоваться прямым поручением владельца, затем AGENTS.md, актуальным STATUS, спецификацией и принятой задачей. Исторические формулировки «safe/confirmed» не заменяют evidence.
