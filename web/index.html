Предпросмотр не выполнялся

Исходный файл не изменяется — правки уходят в новую копию. Сохрани оригинал сам: в браузере нет папки резервных копий.

Десктоп-версия Linux (.deb — установщик Ubuntu/Debian) Linux (.tar.gz — портативный) Windows x64 — установщик (.exe) Windows x64 — portable (.zip) Windows installer ставится в систему и добавляет ярлык; portable ZIP распаковывается в любую папку. .deb ставится двойным кликом или sudo apt install ./stalker2-save-editor_amd64.deb. Десктопная версия нужна для Steam Cloud и журнала резервных копий; браузер работает только с локальной копией.
